# ReelTunes code backend

One Cloudflare Worker serves both the JSON API and the admin dashboard, backed
by one D1 database.

- App API: `https://reeltunes-codes.buildwise.workers.dev`
- Dashboard: same URL, open in a browser and paste the admin token
- D1 database: `reeltunes-codes` (`52fe2891-0753-4787-95df-8a3d11c04ad7`)

## Endpoints

| Method | Path | Auth | Purpose |
|---|---|---|---|
| `GET` | `/api/health` | none | liveness |
| `POST` | `/api/redeem` | none | validate a code, record the grant |
| `GET` | `/api/grant?code=` | none | whether the owner removed this code's effects |
| `GET` | `/api/admin/session` | admin | token check |
| `GET` | `/api/admin/stats` | admin | counters |
| `GET` | `/api/admin/codes` | admin | list codes |
| `POST` | `/api/admin/codes` | admin | create a code |
| `PATCH` | `/api/admin/codes/:code` | admin | revoke / update |
| `DELETE` | `/api/admin/codes/:code` | admin | delete (`?force=1` keeps log clean) |
| `POST` | `/api/admin/codes/:code/remove-effects` | admin | switch off (or restore) the Pro granted by a code |
| `GET` | `/api/admin/redemptions` | admin | recent log |
| `POST` | `/api/admin/revoke-all` | admin | revoke every campaign code |
| `GET/POST` | `/api/admin/master-devices` | admin | master allowlist |
| `DELETE` | `/api/admin/master-devices/:id` | admin | remove a device |

Admin auth is `Authorization: Bearer <ADMIN_TOKEN>` (or `X-Admin-Token`).

## Redeem rules

- Code is uppercased and stripped of spaces, dashes and underscores.
- One redemption per code per device, enforced by a unique index.
- Rejected when revoked, not started, expired, fully used, or already redeemed
  on that device.
- Rate limit: 5 attempts per device per hour, 20 per day.
- A code grants time, never a price. Play owns prices.
- Revoking a code stops future redemptions. Already granted Pro time remains.

The app sends a random device ID and install ID generated by the app. No
account, email, advertising ID or SSAID is sent.

## Deploy

```powershell
# once
npx wrangler d1 create reeltunes-codes
npx wrangler d1 execute reeltunes-codes --remote --file=worker/codes/schema.sql --config worker/codes/wrangler.jsonc

# secrets (choose a long random ADMIN_TOKEN)
Get-Content .scratch\codes-admin-token.txt | npx wrangler secret put ADMIN_TOKEN --config worker/codes/wrangler.jsonc
"YOUR-MASTER-CODE" | npx wrangler secret put MASTER_CODE --config worker/codes/wrangler.jsonc

# existing database: apply new migrations once, in order
npx wrangler d1 execute reeltunes-codes --remote --config worker/codes/wrangler.jsonc --file=worker/codes/migrations/0002_effects_removed.sql

# every change
npx wrangler deploy --config worker/codes/wrangler.jsonc
```

`MASTER_CODE` is optional. It only works from a device listed in
`master_devices`; the string never ships inside the APK.

## Local development

```powershell
npx wrangler dev --config worker/codes/wrangler.jsonc
```

Use `http://127.0.0.1:8787` as the API base and build the app with
`--dart-define=PROMO_API=http://10.0.2.2:8787` (emulator) or your LAN IP.

## Rate limiting and cleanup

Failed and successful attempts both count. Attempts older than two days are
deleted probabilistically during a redeem, so the table stays small without a
cron job.
